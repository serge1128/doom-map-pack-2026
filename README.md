## FAQ

**Do I need GZDoom or can I use another port?**  
GZDoom is recommended. Most maps also work in DSDA-Doom and Crispy DOOM.

**Are all maps for DOOM, DOOM II, or both?**  
Mostly DOOM II. DOOM (1) maps are in a separate subfolder.
